Это **RESTful API** для управления списком задач (Todo), написанный на **Node.js**. Проект служит бэкендом для приложения `todo-api`. В данном проекте не используется `ORM` и `строгая типизация`  

**Маршруты**

`/ - Главная страница`  
`GET /todos — получить все задачи`  
`POST /todos — создать задачу`  
`PUT /todos/:id — обновить задачу (completed)`  
`DELETE /todos/:id — удалить одну задачу`  
`DELETE /todos — удалить все задачи`
